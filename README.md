# 密码管家 · 离线版（PWA 手机APP）

一个**完全离线、无需联网**的账号密码管理手机APP（渐进式网页应用 PWA）。
- 纯 HTML/CSS/JS，无外部 CDN、无服务器、无任何网络请求。
- 数据加密保存在手机浏览器本地（`localStorage`），关闭应用后数据不丢失。
- 支持"添加到主屏幕"变成桌面APP图标，之后断网也能用。
- 支持导出全部账号密码为 **.xlsx** 并分享到微信 / QQ 好友。
- 支持导入 **.xlsx** 文件，自动对比差异生成预览（蓝=新增、绿=修改、红=删除），确认后生效。

> 与仓库根目录的「微信小程序（云开发版）」互不影响，本目录是独立的本地版。

## 导入预览说明

导入文件表头需为：**平台名称 / 账号 / 密码 / 邮箱（选填）/ 创建时间（选填）**。
导入后按"平台名称"与 APP 内数据对比：

- 🔵 **蓝色 = 新增**：文件中存在、APP 中没有的记录，确认后加入 APP。
- 🟢 **绿色 = 修改**：APP 中已存在但账号/密码/邮箱不同的记录，预览显示"旧值 → 新值"，确认后覆盖。
- 🔴 **红色 = 删除**：APP 中存在、文件中没有的记录，预览中划线标红，确认后从 APP 删除。
- 点击**确认导入**则应用预览结果；点击**取消导入**则放弃本次导入，APP 数据不变。

## 安装到手机（二选一）

### 方式 A：HTTPS 托管一次后离线使用（推荐，功能最全）
"添加到主屏幕"与"系统分享面板"需要安全上下文（HTTPS）。把整个 `pwa/` 目录放到任意免费静态托管（GitHub Pages、Cloudflare Pages、Vercel、Netlify 等），手机 Chrome 打开一次，即可安装：

1. 手机 Chrome 打开托管地址（如 `https://你的用户名.github.io/pwa/index.html`）。
2. 点浏览器菜单 → **添加到主屏幕 / 安装应用** → 桌面出现「密码管家」图标。
3. 之后**断网也能正常使用**（Service Worker 已缓存全部文件，数据在本机）。

### 方式 B：直接传文件（无需托管）
把 `pwa/` 目录通过微信/QQ/USB 传到手机，用浏览器打开 `index.html`：
- 增删改查、密码显隐、xlsx 导出与导入**照常可用**；
- 仅"添加到主屏幕"与"一键分享面板"受限（浏览器策略），xlsx 需下载后手动发送。

## 使用说明

1. **首次设置**：设置登录密码（≥6位）+ 密保问题/答案。
2. **登录**：每次打开都停在登录页，输入密码进入；连续输错 10 次锁定 15 分钟。
3. **添加记录**：列表页右下角 ➕，填写平台/账号/密码/邮箱（选填），创建时间自动生成。
4. **编辑/删除**：点记录卡片编辑；列表或编辑页可删除（二次确认）。
5. **隐藏/显示**：点 👁 显示密码，显示后出现 📋 复制按钮。
6. **导出分享 .xlsx**：列表页右上角 📤，自动生成"账号密码备份_日期.xlsx"，弹出系统分享面板选择**微信或QQ**发送给好友；不支持分享的设备会自动下载。
7. **导入 .xlsx**：列表页右上角 📥 选择文件 → 生成差异预览（蓝新增/绿修改/红删除）→ **确认导入**应用、**取消导入**放弃。
8. **忘记密码**：登录页"忘记密码？" → 回答密保问题 → 设置新密码，自动登录且数据不丢。
9. **备份/恢复**：设置页"导出备份"得到加密 JSON（需登录密码解锁）；换手机或重置后选"导入备份"并输入该备份的登录密码即可恢复（与 xlsx 导入互相独立）。
10. **运行自检**：设置页"运行自检"可在真机上一键验证全部核心功能（不影响真实数据）。

## 安全说明

- 登录密码与密保答案均不保存明文；使用 **PBKDF2-SHA256（10万次迭代）** 派生密钥。
- 记录用 **AES-256-GCM** 加密后落盘，本地存储中无任何明文。
- 主密钥分别由"登录密码"和"密保答案"双重包裹：忘记密码时答对密保即可重置，数据不会丢失。
- 数据只存在于你的手机浏览器中，开发者、服务器均无法读取。
- 加密备份（JSON）为密文；导出的 xlsx 为明文（需直接分享给好友查看），请勿转给不信任的人。

## 开发与测试（可选）

本目录为纯静态文件，直接用浏览器打开即可运行。构建期校验脚本（使用项目自带 Node/Python 运行时）：

```powershell
# 1. 生成图标（Python + Pillow）
python tools/make_assets.py

# 2. 功能逻辑自检（Node，覆盖加密/CRUD/密保/备份/xlsx往返/导入差异）
node tools/test-logic.mjs

# 3. 静态校验（JS语法/HTML引用/manifest/sw资源）
node tools/verify-files.mjs

# 4. 端到端冒烟测试（Playwright + 本机 Edge，走完整用户流程，含xlsx导入预览）
node tools/e2e-smoke.mjs
```

手机上也可直接进 **设置 → 运行自检** 完成真机验证。
